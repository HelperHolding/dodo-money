# Ventas BI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pestaña Ventas → BI con los filtros, KPIs, medidores (P.E. y meta), donas y gráficas del dashboard de The Coffee, sobre los pedidos de Dodo IS y Rappi.

**Architecture:** Una migración agrega la tabla `ventas_metas` y dos funciones SQL (`ventas_bi` para el rango filtrado, `ventas_bi_historico` para semanas y meses por año) que devuelven todo agregado en `jsonb`. La app valida filtros y arma rangos en `lib/ventas/bi.ts` (puro, con pruebas), calcula P.E. con el P&L existente y meta con `ventas_metas`, y pinta la página `app/ventas/bi/page.tsx` con componentes SVG propios. Los filtros navegan sin recargar (patrón de `FiltrosDashboard`).

**Tech Stack:** Next.js 15 (server components + server actions), Supabase/Postgres (plpgsql, RLS), PGlite para pruebas SQL, `node --test`, CSS de `app/marca.css`.

**Spec:** `docs/superpowers/specs/2026-11-18-ventas-bi-design.md`

## Global Constraints

- Solo admin y corporativo (`veVentasDeTodas` en la app, `ve_todas_las_sucursales()` en SQL).
- Pedidos de Dodo IS: `estado = 'entregado'` y `tipo <> 'personal'`; venta neta = `total - iva`.
- Rappi: `estado = 'Finalizado'` y `sumar`; venta neta = `subtotal_restaurante * 100 / 116` (mismo IVA que `app/ventas/datos.ts`).
- Líneas: neto = `precio * 100 / 116` (Dodo) o `importe * 100 / 116` (Rappi).
- Con filtro de categoría o producto se cuentan los pedidos que contienen esas líneas y la venta de **esas líneas**; la pantalla lo avisa.
- El filtro de categoría deja fuera a Rappi (Rappi no trae categoría en la base); la pantalla lo avisa.
- Rango máximo 1100 días.
- Sin librerías nuevas; gráficas en SVG; colores solo con tokens (`--dato-*`, `--accion`, `--linea`…).
- La migración se entrega a Sebastián y se corre en producción **antes** de publicar la pantalla (AGENTS.md).
- Flujo: rama `feat/ventas-bi` → PR a `main`; pasan `Historial válido` y `Pruebas y tipos`.

## Review Focus

- **Sucursal sin P&L cerrado o sin meta capturada:** el bloque dice qué falta, no muestra 0 % ni divide entre cero.
- **Margen de contribución ≤ 0** (mes con más costo variable que venta): esa sucursal queda «sin P.E.».
- **Filtros que dejan cero pedidos:** KPIs en 0, donas y gráficas con su estado vacío, sin errores.
- **Fecha relativa en lunes/1 de mes/1 de enero** (rango de un solo día) y comparación «año pasado» con 29 de febrero.
- **Gerente que entra a `/ventas/bi` por URL:** redirige; la función SQL también lo rechaza.
- **Listas vacías como `null` de JSON** (lo que manda `parametrosSQL`): la función no debe tronar; se prueba llamando `ventas_bi` con el objeto completo de `parametrosSQL` (todas las listas en `null`).

Las cuatro primeras se prueban en las Tareas 1 y 2; la quinta en la Tarea 2 (SQL) y la Tarea 5 (guardia de la página).

import { categoriaRappi } from "./rappiProductos.ts";

export type Relativa = "hoy" | "ayer" | "esta_semana" | "semana_pasada" | "este_mes" | "mes_pasado" | "este_anio" | "anio_pasado";
export const RELATIVAS: readonly [Relativa, string][] = [["hoy", "Hoy"], ["ayer", "Ayer"], ["esta_semana", "Esta semana"], ["semana_pasada", "Semana pasada"],
  ["este_mes", "Este mes"], ["mes_pasado", "Mes pasado"], ["este_anio", "Este año"], ["anio_pasado", "Año pasado"]];
export const ORIGENES_BI = ["mostrador", "kiosco", "app", "sitio", "agregador", "rappi"] as const;
export const TIPOS_BI = ["en_tienda", "entrega", "para_llevar"] as const;
export const PAGOS_BI = ["efectivo", "tarjeta", "en_linea", "rappi", "otro"] as const;
export const CATEGORIAS_BI = ["pizza", "snack", "postre", "bebida", "combo", "otro", "sin_categoria"] as const;
export const EDADES_BI = { "0-6": [0, 6], "6-12": [6, 12], "12-24": [12, 24], "24+": [24, null] } as const;
export type FiltrosBI = { rel: Relativa | null; desde: string; hasta: string; comp: "anterior" | "anio"; suc: string[]; rfc: string | null;
  edad: keyof typeof EDADES_BI | null; canal: "pos" | "rappi" | null; origen: string[]; tipo: string[]; dia: number[]; hora: [number, number] | null;
  cat: string[]; prod: string | null; pago: string[] };

const ISO = /^\d{4}-\d{2}-\d{2}$/;
const d = (s: string) => new Date(`${s}T12:00:00Z`);
const iso = (x: Date) => x.toISOString().slice(0, 10);
const mas = (s: string, dias: number) => { const x = d(s); x.setUTCDate(x.getUTCDate() + dias); return iso(x); };
const diasEntre = (a: string, b: string) => Math.round((d(b).getTime() - d(a).getTime()) / 86400000);
const finMes = (s: string) => iso(new Date(Date.UTC(Number(s.slice(0, 4)), Number(s.slice(5, 7)), 0, 12)));
const lista = (v: string | string[] | undefined) => (Array.isArray(v) ? v : v ? [v] : []).flatMap((x) => x.split(",")).map((x) => x.trim()).filter(Boolean);

export function rangoRelativo(rel: Relativa, hoy: string): { desde: string; hasta: string } {
  const lunes = mas(hoy, -((d(hoy).getUTCDay() + 6) % 7)), mes = `${hoy.slice(0, 7)}-01`, anio = Number(hoy.slice(0, 4));
  switch (rel) {
    case "hoy": return { desde: hoy, hasta: hoy };
    case "ayer": return { desde: mas(hoy, -1), hasta: mas(hoy, -1) };
    case "esta_semana": return { desde: lunes, hasta: hoy };
    case "semana_pasada": return { desde: mas(lunes, -7), hasta: mas(lunes, -1) };
    case "este_mes": return { desde: mes, hasta: hoy };
    case "mes_pasado": { const fin = mas(mes, -1); return { desde: `${fin.slice(0, 7)}-01`, hasta: fin }; }
    case "este_anio": return { desde: `${anio}-01-01`, hasta: hoy };
    case "anio_pasado": return { desde: `${anio - 1}-01-01`, hasta: `${anio - 1}-12-31` };
  }
}

const unAnioAntes = (s: string) => { const y = Number(s.slice(0, 4)) - 1, md = s.slice(5); return md === "02-29" ? `${y}-02-28` : `${y}-${md}`; };
export function rangoComparacion(desde: string, hasta: string, comp: "anterior" | "anio") {
  if (comp === "anio") return { desde: unAnioAntes(desde), hasta: unAnioAntes(hasta) };
  const largo = diasEntre(desde, hasta) + 1;
  return { desde: mas(desde, -largo), hasta: mas(desde, -1) };
}

export function leerFiltrosBI(sp: Record<string, string | string[] | undefined>, hoy: string): FiltrosBI {
  const uno = (k: string) => lista(sp[k])[0] ?? null;
  const desdeP = uno("desde"), hastaP = uno("hasta");
  const rangoValido = !!desdeP && !!hastaP && ISO.test(desdeP) && ISO.test(hastaP) && desdeP <= hastaP && hastaP <= hoy && diasEntre(desdeP, hastaP) <= 1100;
  const relP = uno("rel") as Relativa | null;
  const rel: Relativa | null = rangoValido ? null : RELATIVAS.some(([r]) => r === relP) ? relP : "esta_semana";
  const rango = rel ? rangoRelativo(rel, hoy) : { desde: desdeP!, hasta: hastaP! };
  const permitidos = (k: string, valores: readonly string[]) => lista(sp[k]).filter((x) => valores.includes(x));
  const horaM = (uno("hora") ?? "").match(/^(\d{1,2})-(\d{1,2})$/);
  const hora: [number, number] | null = horaM && Number(horaM[1]) <= Number(horaM[2]) && Number(horaM[2]) <= 23 ? [Number(horaM[1]), Number(horaM[2])] : null;
  const edad = uno("edad");
  const prod = (uno("prod") ?? "").trim().slice(0, 80);
  return {
    rel, ...rango, comp: uno("comp") === "anio" ? "anio" : "anterior",
    suc: lista(sp.suc).filter((x) => /^[0-9a-z-]{1,40}$/i.test(x)), rfc: uno("rfc"),
    edad: edad && edad in EDADES_BI ? (edad as keyof typeof EDADES_BI) : null,
    canal: uno("canal") === "pos" || uno("canal") === "rappi" ? (uno("canal") as "pos" | "rappi") : null,
    origen: permitidos("origen", ORIGENES_BI), tipo: permitidos("tipo", TIPOS_BI),
    dia: lista(sp.dia).map(Number).filter((n) => Number.isInteger(n) && n >= 1 && n <= 7), hora,
    cat: permitidos("cat", CATEGORIAS_BI), prod: prod || null, pago: permitidos("pago", PAGOS_BI),
  };
}

export function parametrosSQL(f: FiltrosBI, rango: { desde: string; hasta: string }): Record<string, unknown> {
  const o = <T,>(xs: T[]) => (xs.length ? xs : null);
  const edad = f.edad ? EDADES_BI[f.edad] : null;
  return { desde: rango.desde, hasta: rango.hasta, sucursales: o(f.suc), rfc: f.rfc, edad_min: edad ? edad[0] : null, edad_max: edad ? edad[1] : null,
    canal: f.canal, origenes: o(f.origen), tipos: o(f.tipo), dias: o(f.dia), hora_desde: f.hora?.[0] ?? null, hora_hasta: f.hora?.[1] ?? null,
    categorias: o(f.cat), producto: f.prod, pagos: o(f.pago) };
}

/** Renglones del P&L que suben y bajan con la venta; el resto son fijos. */
export const CLAVES_VARIABLES = ["alimento", "merma", "regalias", "agregadores", "marketing_agregadores", "repartidores"] as const;
export const CLAVES_FIJAS = ["nomina_cocina", "nomina_gerencia", "renta", "servicios", "mantenimiento", "consumibles_equipo", "marketing", "otros", "oficina"] as const;

/** P.E. mensual = fijos ÷ (1 − variables ÷ venta neta). Sin venta, sin dato o margen ≤ 0 → null. */
export function puntoEquilibrio(montos: Record<string, number | null>): number | null {
  const venta = montos.venta_neta;
  if (venta === null || venta === undefined || venta <= 0) return null;
  const suma = (ks: readonly string[]) => ks.reduce((s, k) => s + (montos[k] ?? 0), 0);
  const margen = 1 - suma(CLAVES_VARIABLES) / venta;
  return margen > 0 ? suma(CLAVES_FIJAS) / margen : null;
}

/** Parte de un monto mensual que toca a los días del rango dentro de ese mes ("AAAA-MM"). */
export function prorratear(montoMensual: number, desde: string, hasta: string, mes: string): number {
  const ini = `${mes}-01`, fin = finMes(ini), a = desde > ini ? desde : ini, b = hasta < fin ? hasta : fin;
  if (a > b) return 0;
  return (montoMensual * (diasEntre(a, b) + 1)) / (diasEntre(ini, fin) + 1);
}

export function metaDelRango(metas: { sucursal_id: string; mes: string; monto: number }[], sucursales: string[], desde: string, hasta: string) {
  const meses: string[] = [];
  for (let m = `${desde.slice(0, 7)}-01`; m <= hasta; m = mas(finMes(m), 1)) meses.push(m);
  let monto = 0; const faltan: { sucursal_id: string; mes: string }[] = [];
  for (const s of sucursales) for (const m of meses) {
    const meta = metas.find((x) => x.sucursal_id === s && x.mes === m);
    if (!meta) faltan.push({ sucursal_id: s, mes: m }); else monto += prorratear(Number(meta.monto), desde, hasta, m.slice(0, 7));
  }
  return { monto: Math.round(monto * 100) / 100, faltan };
}

export function mezclarCategorias(pos: { categoria: string; ventas: number }[], rappi: { nombre: string; ventas: number }[]) {
  const t = new Map<string, number>();
  for (const c of pos) t.set(c.categoria, (t.get(c.categoria) ?? 0) + Number(c.ventas));
  for (const r of rappi) { const c = categoriaRappi(r.nombre, null).categoria; t.set(c, (t.get(c) ?? 0) + Number(r.ventas)); }
  return [...t].map(([categoria, ventas]) => ({ categoria, ventas: Math.round(ventas * 100) / 100 })).sort((a, b) => b.ventas - a.ventas);
}

export function urlBI(f: FiltrosBI, cambios: Partial<FiltrosBI> = {}): string {
  const x = { ...f, ...cambios }, q = new URLSearchParams();
  if (x.rel) q.set("rel", x.rel); else { q.set("desde", x.desde); q.set("hasta", x.hasta); }
  q.set("comp", x.comp);
  for (const s of x.suc) q.append("suc", s);
  if (x.rfc) q.set("rfc", x.rfc); if (x.edad) q.set("edad", x.edad); if (x.canal) q.set("canal", x.canal);
  for (const [k, v] of [["origen", x.origen], ["tipo", x.tipo], ["dia", x.dia], ["cat", x.cat], ["pago", x.pago]] as const) for (const i of v) q.append(k, String(i));

create or replace function public.ventas_bi(p jsonb) returns jsonb
language plpgsql stable security invoker set search_path = public as $$
declare
  v_desde date := (p->>'desde')::date;
  v_hasta date := (p->>'hasta')::date;
  v_canal text := nullif(p->>'canal', '');
  v_origenes text[] := case when (case when jsonb_typeof(p->'origenes') = 'array' then jsonb_array_length(p->'origenes') else 0 end) > 0 then array(select jsonb_array_elements_text(p->'origenes')) end;
  v_tipos text[] := case when (case when jsonb_typeof(p->'tipos') = 'array' then jsonb_array_length(p->'tipos') else 0 end) > 0 then array(select jsonb_array_elements_text(p->'tipos')) end;
  v_pagos text[] := case when (case when jsonb_typeof(p->'pagos') = 'array' then jsonb_array_length(p->'pagos') else 0 end) > 0 then array(select jsonb_array_elements_text(p->'pagos')) end;
  v_cats text[] := case when (case when jsonb_typeof(p->'categorias') = 'array' then jsonb_array_length(p->'categorias') else 0 end) > 0 then array(select jsonb_array_elements_text(p->'categorias')) end;
  v_dias int[] := case when (case when jsonb_typeof(p->'dias') = 'array' then jsonb_array_length(p->'dias') else 0 end) > 0 then array(select jsonb_array_elements_text(p->'dias')::int) end;
  v_h1 int := coalesce((p->>'hora_desde')::int, 0);
  v_h2 int := coalesce((p->>'hora_hasta')::int, 23);
  v_prod text := nullif(trim(p->>'producto'), '');
  v_linea boolean;
  r jsonb;
begin
  if not coalesce(public.ve_todas_las_sucursales(), false) then
    raise exception 'Solo admin y corporativo ven Ventas BI' using errcode = '42501';
  end if;
  if v_desde is null or v_hasta is null or v_hasta < v_desde or v_hasta - v_desde > 1100 then
    raise exception 'Rango de fechas inválido' using errcode = '22023';
  end if;
  v_linea := v_cats is not null or v_prod is not null;

  with suc as (select public.ventas_bi_sucursales(p, v_hasta) as id),
  ped as (
    select 'pos'::text as canal, pe.dodo_id::text as id, pe.sucursal_id, pe.fecha, extract(hour from pe.hora)::int as hora,
      case when pe.agregador is not null then 'agregador' else pe.origen end as origen,
      case when pe.tipo = 'entrega' then 'entrega' when pe.para_llevar then 'para_llevar' else 'en_tienda' end as tipo,
      pe.pago, round(pe.total - pe.iva, 2) as neto, pe.productos as piezas
    from pedidos pe join suc on suc.id = pe.sucursal_id
    where pe.fecha between v_desde and v_hasta and pe.estado = 'entregado' and pe.tipo <> 'personal' and (v_canal is null or v_canal = 'pos')
    union all
    select 'rappi', ro.rappi_id, ro.sucursal_id, ro.fecha, extract(hour from ro.hora)::int, 'rappi', 'entrega', 'rappi',
      round(ro.subtotal_restaurante * 100 / 116, 2), coalesce((select sum(l.cantidad) from rappi_lineas l where l.rappi_id = ro.rappi_id), 0)::int
    from rappi_ordenes ro join suc on suc.id = ro.sucursal_id
    where ro.fecha between v_desde and v_hasta and ro.estado = 'Finalizado' and ro.sumar and (v_canal is null or v_canal = 'rappi') and v_cats is null
  ),
  ped_f as (
    select * from ped
    where (v_origenes is null or origen = any(v_origenes)) and (v_tipos is null or tipo = any(v_tipos)) and (v_pagos is null or pago = any(v_pagos))
      and (v_dias is null or extract(isodow from fecha)::int = any(v_dias)) and hora between v_h1 and v_h2
  ),
  lin as (
    select pf.id, pf.canal, pp.nombre,
      coalesce(pv.categoria::text, case when pp.combo is not null then 'combo' else 'sin_categoria' end) as categoria,
      round(pp.precio * 100 / 116, 2) as neto, 1 as piezas
    from ped_f pf join pedido_productos pp on pf.canal = 'pos' and pp.pedido_id = pf.id
    left join productos_venta pv on pv.dodo_id = pp.dodo_id
    union all
    select pf.id, pf.canal, rl.nombre, 'rappi', round(rl.importe * 100 / 116, 2), rl.cantidad
    from ped_f pf join rappi_lineas rl on pf.canal = 'rappi' and rl.rappi_id = pf.id
  ),
  lin_f as (
    select * from lin where (v_cats is null or categoria = any(v_cats)) and (v_prod is null or nombre ilike '%' || v_prod || '%')
  ),
  pv as (
    select pf.canal, pf.id, pf.sucursal_id, pf.fecha, pf.hora, pf.origen, pf.tipo, pf.pago,
      case when v_linea then x.neto else pf.neto end as venta, case when v_linea then x.piezas else pf.piezas end as unidades
    from ped_f pf left join (select id, canal, sum(neto) as neto, sum(piezas) as piezas from lin_f group by id, canal) x on x.id = pf.id and x.canal = pf.canal
    where not v_linea or x.id is not null
  )
  select jsonb_build_object(
    'kpis', (select jsonb_build_object('ventas', coalesce(sum(venta), 0), 'tickets', count(*), 'productos', coalesce(sum(unidades), 0)) from pv),
    'canales', coalesce((select jsonb_agg(jsonb_build_object('canal', canal, 'ventas', v, 'tickets', t) order by v desc) from (select canal, sum(venta) v, count(*) t from pv group by canal) a), '[]'),
    'origenes', coalesce((select jsonb_agg(jsonb_build_object('origen', origen, 'ventas', v, 'tickets', t) order by v desc) from (select origen, sum(venta) v, count(*) t from pv group by origen) a), '[]'),
    'tipos', coalesce((select jsonb_agg(jsonb_build_object('tipo', tipo, 'ventas', v, 'tickets', t) order by v desc) from (select tipo, sum(venta) v, count(*) t from pv group by tipo) a), '[]'),
    'pagos', coalesce((select jsonb_agg(jsonb_build_object('pago', pago, 'ventas', v, 'tickets', t) order by v desc) from (select pago, sum(venta) v, count(*) t from pv group by pago) a), '[]'),
    'pagos_sucursal', coalesce((select jsonb_agg(jsonb_build_object('sucursal_id', sucursal_id, 'pago', pago, 'ventas', v)) from (select sucursal_id, pago, sum(venta) v from pv group by sucursal_id, pago) a), '[]'),
    'dias', coalesce((select jsonb_agg(jsonb_build_object('dia', dia, 'ventas', v, 'tickets', t) order by dia) from (select extract(isodow from fecha)::int dia, sum(venta) v, count(*) t from pv group by 1) a), '[]'),
    'horas', coalesce((select jsonb_agg(jsonb_build_object('hora', hora, 'ventas', v, 'tickets', t) order by hora) from (select hora, sum(venta) v, count(*) t from pv group by hora) a), '[]'),
    'semanas', coalesce((select jsonb_agg(jsonb_build_object('semana', semana, 'ventas', v, 'tickets', t) order by semana) from (select date_trunc('week', fecha)::date semana, sum(venta) v, count(*) t from pv group by 1) a), '[]'),
    'categorias', coalesce((select jsonb_agg(jsonb_build_object('categoria', categoria, 'ventas', v, 'piezas', u) order by v desc) from (select categoria, sum(neto) v, sum(piezas) u from lin_f where canal = 'pos' and id in (select id from pv where canal = 'pos') group by categoria) a), '[]'),
    'productos', coalesce((select jsonb_agg(jsonb_build_object('nombre', nombre, 'canal', canal, 'ventas', v, 'piezas', u, 'pedidos', t) order by v desc) from (
      select nombre, canal, sum(neto) v, sum(piezas) u, count(distinct id) t from lin_f where (canal, id) in (select canal, id from pv) group by nombre, canal order by v desc limit 200) a), '[]'),
    'rappi_nombres', coalesce((select jsonb_agg(jsonb_build_object('nombre', nombre, 'ventas', v)) from (select nombre, sum(neto) v from lin_f where canal = 'rappi' and id in (select id from pv where canal = 'rappi') group by nombre) a), '[]')
  ) into r;
  return r;
end $$;

import type { SupabaseClient } from "@supabase/supabase-js";

import { metaDelRango, parametrosSQL, puntoEquilibrio, prorratear, rangoComparacion, type FiltrosBI } from "@/lib/ventas/bi";

export type ResultadoBI = Record<string, any>;

/** Último mes cerrado: el anterior al mes de `hoy`. */
const mesCerrado = (hoy: string) => { const x = new Date(`${hoy.slice(0, 7)}-01T12:00:00Z`); x.setUTCDate(0); return { desde: `${x.toISOString().slice(0, 7)}-01`, hasta: x.toISOString().slice(0, 10) }; };

export async function datosBI(supabase: SupabaseClient, f: FiltrosBI, hoy: string, sucursales: { id: string }[]) {
  const comp = rangoComparacion(f.desde, f.hasta, f.comp);
  const elegidas = f.suc.length ? f.suc : sucursales.map((s) => s.id);
  const cerrado = mesCerrado(hoy);
  const [actual, anterior, historico, metas, pl] = await Promise.all([
    supabase.rpc("ventas_bi", { p: parametrosSQL(f, f) }),
    supabase.rpc("ventas_bi", { p: parametrosSQL(f, comp) }),
    supabase.rpc("ventas_bi_historico", { p: parametrosSQL(f, f) }),
    supabase.from("ventas_metas").select("sucursal_id, mes, monto").gte("mes", `${f.desde.slice(0, 7)}-01`).lte("mes", f.hasta),
    datosPL(supabase, cerrado).catch(() => null),
  ]);
  if (actual.error || anterior.error || historico.error) throw new Error("No se pudo calcular Ventas BI.");
  // P.E. del rango: P.E. mensual de cada sucursal (mes cerrado) prorrateado a los días del rango.
  const sinPE: string[] = [];
  let pe = 0;
  for (const id of elegidas) {
    const s = pl?.porSucursal.find((x) => x.id === id);
    const montos = s ? Object.fromEntries(calcularPL(s.entrada, s.metas, s.ctx).map((r) => [r.clave, r.monto])) : null;
    const mensual = montos ? puntoEquilibrio(montos) : null;
    if (mensual === null) { sinPE.push(id); continue; }
    for (let m = `${f.desde.slice(0, 7)}`; m <= f.hasta.slice(0, 7); m = new Date(Date.UTC(Number(m.slice(0, 4)), Number(m.slice(5, 7)), 1)).toISOString().slice(0, 7)) pe += prorratear(mensual, f.desde, f.hasta, m);
  }
  const meta = metaDelRango((metas.data ?? []) as { sucursal_id: string; mes: string; monto: number }[], elegidas, f.desde, f.hasta);
  return { actual: actual.data as ResultadoBI, anterior: anterior.data as ResultadoBI, historico: historico.data as ResultadoBI, comp,
    pe: { monto: Math.round(pe * 100) / 100, sinPE, mesCerrado: cerrado.desde.slice(0, 7) }, meta };
