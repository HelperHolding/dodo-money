# Conector de Grok (MCP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un endpoint MCP de solo lectura, `/api/mcp`, que un Grok Bot consulta con una llave Bearer para leer ventas, cortes, costos, manuales y P&L de dodo-money.

**Architecture:** La lógica vive en `lib/mcp/` en módulos puros y testeables:
- `auth.ts`: comparación de la llave.
- `protocolo.ts`: JSON-RPC.
- `herramientas.ts`: esquemas, validación y URL absolutas.
- `servidor.ts`: orquestación con dependencias inyectadas.
- `ejecutar.ts`: llamadas a `consultasIA`.

`app/api/mcp/route.ts` solo conecta las variables de entorno, la sesión de la cuenta de servicio en Supabase y las RPC de registro. Una migración agrega `mcp_llamadas` y las funciones de reserva y cierre con límites.

**Tech Stack:** Next.js 15 (route handler, runtime nodejs), `@supabase/supabase-js`, PostgreSQL (Supabase) y pruebas con `node --test`: `--experimental-strip-types` para `.ts` puros, cargador `.cjs` con transpilación para módulos con alias `@/`, y PGlite para SQL.

**Spec:** `docs/superpowers/specs/2026-11-19-grok-mcp-design.md`

## Global Constraints

- Solo lectura: ninguna herramienta escribe datos de negocio; las únicas escrituras son `mcp_reservar_llamada` y `mcp_cerrar_llamada`.
- Sin dependencias nuevas (nada de `@modelcontextprotocol/sdk`).
- Variables de entorno: `GROK_MCP_KEY`, `GROK_MCP_CUENTA_EMAIL`, `GROK_MCP_CUENTA_PASSWORD` (más las existentes `NEXT_PUBLIC_SUPABASE_URL` y `NEXT_PUBLIC_SUPABASE_ANON_KEY`).
- Versiones MCP soportadas: `2025-06-18` y `2025-03-26`, la más reciente primero.
- Límites: 10 llamadas por minuto y 300 por día (`America/Mexico_City`) por cuenta. Tiempo límite de 45 s por consulta y `maxDuration=60`. Cuerpo máximo de 65,536 caracteres.
- Herramientas: exactamente `sucursales`, `ventas`, `cortes`, `costos`, `manuales` y `pl`.
- Mensajes al usuario en español. Desconocido no es cero: un error siempre es `isError`, nunca un resultado vacío.
- La llave nunca va en URLs, logs ni respuestas.
- Flujo de repo (AGENTS.md): rama `feat/grok-mcp` → PR a `main`. Sin commits vacíos y sin `--no-verify`. Sebastián corre la migración antes del merge.
- Migración: `supabase/migrations/20261119120000_grok_mcp.sql`; pruebas: `supabase/pruebas/20261119120000_grok_mcp.sql`, que termina en `PRUEBAS OK`.

## Review Focus

1. Grok manda `sucursal` como nombre ("Zapopan-1 La Calma") en lugar de id → error claro que mande a usar `sucursales`, no cero ni consolidado silencioso (Task 3).
2. Grok omite `arguments`, o manda `sucursal` como `""` o `null` → se trata como `{}` o como consolidado, sin error (Tasks 3 y 5).
3. Encabezado `bearer` en minúsculas o con espacios alrededor → se acepta; `Basic …` o una llave con un carácter de más → 401 (Task 1).
4. La consulta sale bien pero el registro no se puede cerrar → error claro («La respuesta no pudo registrarse…»), nunca datos sin auditoría (Task 5).
5. Rango con `desde` posterior a `hasta`, o fechas imposibles (2026-02-30) → error de validación, sin llegar a Supabase (Task 3).

```ts
import {createHash,timingSafeEqual} from 'node:crypto';

// Compara hashes de igual longitud para no filtrar por tiempo ni la longitud de la llave.
const huella=(s:string)=>createHash('sha256').update(s,'utf8').digest();
export function llaveValida(autorizacion:string|null,esperada:string):boolean {
 if(!esperada||!autorizacion)return false;
 const m=/^Bearer\s+(\S+)$/i.exec(autorizacion.trim());
 if(!m)return false;
 return timingSafeEqual(huella(m[1]),huella(esperada));
}
```

```ts
// JSON-RPC 2.0 mínimo para MCP sin estado (Streamable HTTP con respuestas JSON).
export const VERSIONES=['2025-06-18','2025-03-26'] as const;
export type Id=string|number;
export type Peticion={id?:Id;method:string;params?:Record<string,unknown>};
export type Respuesta={jsonrpc:'2.0';id:Id|null;result?:unknown;error?:{code:number;message:string}};

export const ok=(id:Id,result:unknown):Respuesta=>({jsonrpc:'2.0',id,result});
export const fallo=(id:Id|null,code:number,message:string):Respuesta=>({jsonrpc:'2.0',id,error:{code,message}});
export const esRespuesta=(x:Peticion|Respuesta):x is Respuesta=>'jsonrpc' in x;

export function leerPeticion(raw:string):Peticion|Respuesta {
 let v:unknown;
 try{v=JSON.parse(raw);}catch{return fallo(null,-32700,'JSON inválido.');}
 if(Array.isArray(v))return fallo(null,-32600,'No se aceptan lotes.');
 if(!v||typeof v!=='object')return fallo(null,-32600,'Petición inválida.');
 const o=v as Record<string,unknown>,id=o.id;
 if(id!==undefined&&typeof id!=='string'&&!(typeof id==='number'&&Number.isInteger(id)))return fallo(null,-32600,'Petición inválida.');
 const params=o.params;
 if(o.jsonrpc!=='2.0'||typeof o.method!=='string'||(params!==undefined&&(typeof params!=='object'||params===null||Array.isArray(params))))return fallo((id as Id|undefined)??null,-32600,'Petición inválida.');
 return {id:id as Id|undefined,method:o.method,params:params as Record<string,unknown>|undefined};
}

export function inicializar(pedida:unknown,instrucciones:string) {
 const protocolVersion=(VERSIONES as readonly unknown[]).includes(pedida)?pedida as string:VERSIONES[0];
 return {protocolVersion,capabilities:{tools:{}},serverInfo:{name:'dodo-money',version:'1.0.0'},instructions:instrucciones};
}

export const resultadoTexto=(valor:unknown,isError=false)=>({content:[{type:'text' as const,text:typeof valor==='string'?valor:JSON.stringify(valor)}],...(isError?{isError:true as const}:{})});
```

```ts
 if(typeof a.clave!=='string'||!patron.test(a.clave))throw Error('clave inválida: mes YYYY-MM o semana YYYY-Wnn.');
 return {herramienta:'pl',tipo:a.tipo,clave:a.clave,sucursal:sucursalOpcional(a.sucursal)};
}

// Solo `fuente` y `href` que empiezan con una sola "/" son enlaces internos de dodo-money.
export function absolutizar(valor:unknown,origen:string):unknown {
 if(Array.isArray(valor))return valor.map(v=>absolutizar(v,origen));
 if(valor&&typeof valor==='object')return Object.fromEntries(Object.entries(valor).map(([k,v])=>[k,(k==='fuente'||k==='href')&&typeof v==='string'&&v.startsWith('/')&&!v.startsWith('//')?origen+v:absolutizar(v,origen)]));
 return valor;
}
```

```ts
export async function manejarMCP(e:Entrada,d:Dependencias):Promise<Salida> {
 if(!d.llave||!d.configurada)return {status:503,cuerpo:{error:'Conector no configurado.'}};
 if(!llaveValida(e.autorizacion,d.llave))return {status:401,cuerpo:{error:'No autorizado.'}};
 if(e.metodo!=='POST')return {status:405,cuerpo:{error:'Método no permitido.'}};
 if(e.cuerpo.length>LIMITE_CUERPO)return {status:413,cuerpo:fallo(null,-32600,'Petición demasiado grande.')};
 const p=leerPeticion(e.cuerpo);
 if(esRespuesta(p))return {status:400,cuerpo:p};
 if(p.id===undefined)return {status:202};
 switch(p.method){
  case 'initialize':return {status:200,cuerpo:ok(p.id,inicializar(p.params?.protocolVersion,INSTRUCCIONES))};
  case 'ping':return {status:200,cuerpo:ok(p.id,{})};
  case 'tools/list':return {status:200,cuerpo:ok(p.id,{tools:HERRAMIENTAS})};
  case 'tools/call':return {status:200,cuerpo:ok(p.id,await llamar(p.params,d))};
  default:return {status:200,cuerpo:fallo(p.id,-32601,'Método no soportado.')};
 }
}

async function llamar(params:Record<string,unknown>|undefined,d:Dependencias) {
 let a:Argumentos,c:Conexion,id:string;
 try{a=validarArgumentos(params?.name,params?.arguments??{});}catch(e){return resultadoTexto(mensaje(e),true);}
 try{c=await d.conectar();}catch(e){return resultadoTexto(mensaje(e),true);}
 const {herramienta,...argumentos}=a;
 try{id=await c.reservar(herramienta,argumentos);}catch(e){return resultadoTexto(mensaje(e),true);}
 let r:unknown;
 try{r=await conTiempo(c.ejecutar(a),d.tiempoLimite??45000);}
 catch(e){const m=mensaje(e);await c.cerrar(id,'error',m).catch(()=>{});return resultadoTexto(m,true);}
 try{await c.cerrar(id,'completada',null);}catch{return resultadoTexto('La respuesta no pudo registrarse. Vuelve a intentar.',true);}
 return resultadoTexto(r);
}
```

```ts
// Conector MCP de solo lectura para Grok Bot (docs/superpowers/specs/2026-11-19-grok-mcp-design.md).
async function conectar(origen:string):Promise<Conexion> {
 const supabase=createClient(process.env.NEXT_PUBLIC_SUPABASE_URL!.trim(),process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!.trim(),{auth:{persistSession:false,autoRefreshToken:false}});
 const {data,error}=await supabase.auth.signInWithPassword({email:process.env.GROK_MCP_CUENTA_EMAIL!,password:process.env.GROK_MCP_CUENTA_PASSWORD!});

   return id;
  },

 });
 const headers={'Cache-Control':'no-store'};
 return s.cuerpo===undefined?new NextResponse(null,{status:s.status,headers}):NextResponse.json(s.cuerpo,{status:s.status,headers});
}
```
